Условные предложения (Conditionals)

Условные предложения (Conditionals) — это предложения, которые описывают условие и его результат. Они состоят из двух частей: if-clause (придаточное условия) и main clause (главное предложение).

🟢 Zero Conditional / Нулевой тип

Использование / Use: Для общих истин, научных фактов, законов природы, регулярных действий. / For general truths, scientific facts, laws of nature, regular actions.

If + Present Simple, Present Simple
If you heat ice, it melts.
Если нагреть лёд, он тает.
If it rains, the ground gets wet.
Если идёт дождь, земля становится мокрой.

🔵 First Conditional / Первый тип

Использование / Use: Для реальных и вероятных ситуаций в настоящем или будущем. / For real and probable situations in the present or future.

If + Present Simple, will + V (infinitive)
If it rains tomorrow, I will stay at home.
Если завтра пойдёт дождь, я останусь дома.
If you study hard, you will pass the exam.
Если ты будешь усердно учиться, ты сдашь экзамен.

🟡 Second Conditional / Второй тип

Использование / Use: Для нереальных или маловероятных ситуаций в настоящем или будущем; для советов. / For unreal or improbable situations in the present or future; for advice.

If + Past Simple, would + V (infinitive)
If I had a million dollars, I would buy a house.
Если бы у меня был миллион долларов, я бы купил дом.
If I were you, I would apologize.
Если бы я был на твоём месте, я бы извинился.

Важно: В условной части после if для всех лиц используется were (а не was). / Important: In the if-clause we use were for all persons (not was).

🔴 Third Conditional / Третий тип

Использование / Use: Для нереальных ситуаций в прошлом; сожаления о том, что нельзя изменить. / For unreal situations in the past; regrets about things that cannot be changed.

If + Past Perfect (had + V3), would have + V3
If I had studied harder, I would have passed the exam.
Если бы я учился усерднее, я бы сдал экзамен.
If she had called me, I would have come.
Если бы она мне позвонила, я бы пришёл.
